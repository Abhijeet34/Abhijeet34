### What I work on

I build software systems and the tooling around them. Most of my recent work sits in two places: full-stack products (Flask and FastAPI on the backend, JavaScript on the front) and the DevOps that ships them (Docker, Jenkins, Kubernetes, SonarQube, Prometheus, Grafana). I care about the parts that are easy to skip and expensive to skip: verification loops, CI checks that actually fail on real problems, and defaults that carry the common path so a normal run needs no ceremony.

I am moving deeper into AI-assisted development. The interesting problem is not "call a bigger model." It is giving a smaller, local model the right tools, context, and verification loop so the harness does the heavy lifting. Local-first should be the baseline, not a fallback.

Verification matters more than confidence.

### Currently building toward

- **Agentic workflows and harnesses** that let a model plan, act, and check its own work instead of guessing in one shot.
- **Local-first developer tooling** that reduces overdependence on expensive cloud APIs without giving up quality.
- **Reproducible delivery pipelines** where the checks (tests, lint, static analysis, observability) are part of the definition of done, not an afterthought.
